# dsh-workspace-folders

[English](README.md) | 日本語

DeepSeek Harness の Web GUI で サイドバーのワークスペースをフォルダに分けて並べる
プラグインです フォルダは入れ子にでき フォルダとワークスペースにアイコンを付けられます
アイコンは Discord のような検索できるピッカーで 絵文字か DSH の UI のアイコンから選べます
ロゴなどの好きな画像も追加して使えます

```
▾ 🛠️ DSHプラグイン
│  ▾ 📁 UI
│  │  📁 dsh-ui-cost-meter
│  │  📁 dsh-workspace-folders
│  📁 dsh-locale-ja
▸ 🏠 Vault                3
▾ 📁 未分類
   📁 dotfiles
```

純正のワークスペース一覧は置き換えません 一覧の中へフォルダの見出し行を差し込み
純正のワークスペースの並びと字下げだけを変えます そのためセッションの「…」メニュー
ステータスの点 ピン留め 検索 表示オプションは純正のまま使えます

## 導入

```sh
dsh plugin --profile web add github:yuu1111/dsh-workspace-folders
```

ソースから使う場合は `add link:<path>` でも同じです プラグインが自分の bundle patch を
持っているため profile の `cordis.patch.yml` を書き換えなくても行が入ります 入れたあと
`dsh web` を起動し直してください

## 使い方

| 操作 | 方法 |
|---|---|
| フォルダを作る | ワークスペースの見出しにあるフォルダのボタン または「未分類」の「…」 |
| サブフォルダを作る | フォルダ行の「…」→ サブフォルダを作成 |
| ワークスペースを入れる | ワークスペース行をフォルダ行へドラッグ または フォルダ行の「…」→ ワークスペースを入れる |
| フォルダから出す | ワークスペース行を「未分類」へドラッグ |
| フォルダを並び替える | フォルダ行を別のフォルダ行の上端か下端へドラッグ または「…」→ 上へ移動・下へ移動 |
| フォルダを別のフォルダへ入れる | フォルダ行を別のフォルダ行の真ん中へドラッグ または「…」→ 移動 |
| アイコンを変える | フォルダ行の「…」→ アイコンを変更 |
| ワークスペースのアイコンを変える | ワークスペース行の「…」→ アイコンを変更 |
| 好きな画像をアイコンにする | ピッカーの「カスタム」の「＋」 または画像をピッカーへドロップか貼り付け |
| 開閉 | フォルダ行をクリック 閉じたフォルダには中のワークスペースの数が出ます |

フォルダを消すと 中のワークスペースとサブフォルダは1つ上の階層へ移ります
ワークスペースそのものとセッションは消えません

フォルダが1つも無いあいだは 純正の一覧に何もしません

追加した画像は 64px の PNG に縮めて保存します 透過の背景に単色で描かれたロゴは
テーマの文字色で塗るため 暗いテーマでも見えます 画像にカーソルを合わせて出る「×」で
消すと それを使っていたフォルダとワークスペースは既定のアイコンへ戻ります

## 保存先

フォルダと割り当てとアイコンと追加した画像はブラウザの `localStorage`（`dsh-workspace-folders.state.v1`）に
保存します ブラウザごとの設定になり DSH のワークスペースの登録や並び順は変えません

## 制約

- 純正の一覧の DOM の形（`[data-slot="sidebar.workspaces"]` の中の `role="tree"` と
  行の `data-row-key`）に合わせて CSS を当てています DSH の更新でこの形が変わると
  フォルダ行の位置がずれることがあります その場合でも純正の一覧と機能はそのまま動きます
- 純正の表示オプションの「1つのリストにまとめる」ではワークスペースの群が無いため
  フォルダは出ません
- DeepSeek Harness 0.2.1-rc.2 の Web GUI で確かめています
